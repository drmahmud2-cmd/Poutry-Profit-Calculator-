# Poultry Profit Lab

A free, single-file poultry farm profit calculator for broilers and layers, built for learning.

## Features
- Broiler and layer (egg) modes
- Costs, revenue, net profit, ROI, margin and break-even price in Naira (₦)
- Feed conversion ratio (FCR) and feed usage in bags
- Cost breakdown chart and plain-language insights
- Scenario comparison and price stress tests
- Teaching notes and glossary
- Print or save as PDF for class handouts

## Use
Open `index.html` in any browser. No install or internet needed.

## Disclaimer
Example values are rough estimates for teaching. Use your own farm records for real decisions.
